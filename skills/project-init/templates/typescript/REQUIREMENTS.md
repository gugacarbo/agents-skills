# TypeScript requirements

## Core Dependencies

- `typescript` for compilation and type checking.

## Dev Dependencies

- `vitest` for tests.
- `@biomejs/biome` for linting and formatting.
- `knip` for dead-code and dependency analysis.
- `husky` for Git hook delegation.

## CI/CD

- Type checking, tests, Biome, Knip, and build must pass on pull requests.

## Skills

- `project-init` for convention overlays on fresh projects.
- `commit-changes` for commits.
- `code-flow` for multi-step delivery.
