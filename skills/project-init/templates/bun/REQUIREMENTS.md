# Bun requirements

## Core Dependencies

- `bun init` owns TypeScript declarations and initial configuration.

## Dev Dependencies

- `@biomejs/biome`, `knip`, and `husky`.

## Built-in tools

- `bun test`, `bun build`, and `bun --watch`.

## CI/CD

- Run Bun typecheck, tests, Biome, Knip, and the production build.
