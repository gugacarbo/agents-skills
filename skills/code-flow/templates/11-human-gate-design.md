# Gate humano: design (Fase 1)

**Em jogo:** o design de entrega (abordagem, limites, exclusões, verificação)
antes de criar issue, ADR/spec formal, plano ou implementação.

**Você aprova:** este design como base da Fase 2 (source-set / issue).

Responda com uma opção literal:

- **Yes** — design aprovado; seguir para a Fase 2.
- **No** — rejeitar; explicar o que está errado.
- **Refine** — pedir mudança concreta; o orquestrador revisa e repregunta.

Não muda labels GitHub. Sem Yes explícito, não avançar.
