# Task Progress Log

This file is append-only. Each line is a JSON object written by subagents via `scripts/log-task.sh`.

## Event Format

The `log-task.sh` script appends one JSON object per line:

```json
{"timestamp":"ISO8601","task":"Task-X-NNNN","event":"started|completed|failed|blocked","try":1,"maxTries":3,"message":"human-readable note"}
```

## Supported Events

- `started`   — subagent began working on the task
- `completed` — subagent finished the task and all acceptance criteria are met
- `failed`     — subagent encountered an error and will retry (if retries remain)
- `blocked`   — subagent cannot proceed without external input or decision

Note: event values are **lowercase**. The script only accepts `started|completed|failed|blocked`.

## Example Log

```json
{"timestamp":"2026-06-30T20:15:10Z","task":"Task-A-0001","event":"started","try":1,"maxTries":3,"message":"Initializing task environment"}
{"timestamp":"2026-06-30T20:15:45Z","task":"Task-A-0001","event":"completed","try":1,"maxTries":3,"message":"Tests pass, files committed"}
{"timestamp":"2026-06-30T20:16:02Z","task":"Task-B-0001","event":"started","try":1,"maxTries":3,"message":"Starting core implementation"}
{"timestamp":"2026-06-30T20:17:30Z","task":"Task-B-0001","event":"failed","try":1,"maxTries":3,"message":"Lint errors in src/core.py"}
{"timestamp":"2026-06-30T20:18:05Z","task":"Task-B-0001","event":"started","try":2,"maxTries":3,"message":"Retrying after lint fixes"}
{"timestamp":"2026-06-30T20:19:12Z","task":"Task-B-0001","event":"blocked","try":2,"maxTries":3,"message":"Needs decision on error handling approach"}
```

## Location

Save the log in the task directory alongside `tasks.json`:

```
docs/tasks/{NNNN-<feature-name>}/progress.log
```

## Rules

- Append only — never edit or delete existing lines.
- Do not write to this file directly. Use `scripts/log-task.sh` to avoid race conditions.
- The orchestrator agent reads this log to determine current state; keep messages concise and factual.
- After context compaction, trust this log and `git log` over your own recollection.
