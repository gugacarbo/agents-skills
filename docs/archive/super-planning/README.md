# Arquivo histórico: super-planning

Estes documentos registram o dashboard de jobs e os watchdogs da antiga
`super-planning`. Ambos foram descontinuados: a automação atual está na
`code-toolbox` e usa issues, comentários e PRs do GitHub como evidência, sem
`docs/jobs`, registros locais ou watchdogs.

Os arquivos deste diretório são apenas referência histórica e não definem
comportamento ativo.
